# Diabetic Detection 🩺 - Predictive Classification System

A machine learning system that predicts diabetes risk from patient diagnostic data. 🏆 Best Project Award 2026, MIT-ADT University.

## Problem
Missing a positive diabetes case is costly, so this project focuses on **recall** to reduce missed cases.

## What I did
- Worked with 500+ patient diagnostic records
- Cleaned the data and did exploratory data analysis (EDA)
- Encoded categorical variables and handled class imbalance through feature engineering
- Trained and compared multiple Scikit-learn classifiers using cross-validation
- Selected the best model; F1-score improved by 12% after cross-validation
- Identified key clinical risk factors through statistical analysis

## Tech Stack
Python, Pandas, NumPy, Scikit-Learn
